# OpenPayload Public Repository

This repository hosts public OpenPayload components and provides a place for bug reports, support requests, documentation feedback, feature requests, and community interaction. The [community full node](openpayload-community-node/README.md) is the first published component.

## Source and licensing

The community full node source, build instructions, and live chain specification are in [`openpayload-community-node/`](openpayload-community-node/). Its project-authored source is released under the [Unlicense](openpayload-community-node/LICENSE). One upstream-derived runtime file retains its Apache 2.0 notice; see the [component license notes](openpayload-community-node/README.md#security-and-licensing) and [Apache license text](openpayload-community-node/LICENSE-APACHE). Future components may have their own licenses in their folders.

All public submissions should be safe for public disclosure. Do not include confidential information, credentials, source code from private repositories, proprietary technical details, customer information, personal information, or security-sensitive material.

## Reporting Issues

Use [GitHub Issues](../../issues) to report public bugs, ask public support questions, or request features. Choose the issue form that best matches your request and provide clear, sanitized information that maintainers can use to understand the report.

Bug reports should include a concise summary, reproduction steps, expected behavior, actual behavior, platform details, application version, and sanitized logs or screenshots when helpful. Please describe behavior rather than private implementation details, and remove secrets, customer information, proprietary source code, and security-sensitive material before submitting.

Do not report security vulnerabilities through public issues. Follow the private process in the [Security Policy](.github/SECURITY.md).
